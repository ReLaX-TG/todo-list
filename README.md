# To-Do List

A simple and responsive task management web application built with HTML, CSS, and JavaScript using AI-assisted development.

## Live Demo

https://relax-tg.github.io/todo-list/

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using browser localStorage
- Keep tasks after refreshing the page
- Clean and simple interface

## Technologies

- HTML5
- CSS3
- JavaScript
- localStorage
